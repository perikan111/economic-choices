# パンの値段を下げろ！ 本番シナリオ

市長としてパン価格の高騰に向き合い、価格・供給・財政・食料へのアクセスのトレードオフを体験する第一作です。

- 35シーン（うち5シーンは分岐・条件付きeffect専用）
- 3回の政策判断と、摘発・届出制・黙認・価格緩和から選ぶ非公式市場イベント
- 22選択肢
- 8種類のエンディング
- エンディング末尾のEconomics解説

シナリオversionは `1.1.0`。非公式市場の規模と取引上の不確実性を分けて扱い、登録制を選ぶと `informalRegistered` が記録されます。

シナリオ内容の一次情報は `docs/scenarios/bread-price-design.md`、データ形式は `docs/scenario-format.md` を参照してください。
